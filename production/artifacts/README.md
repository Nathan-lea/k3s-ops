# =============================================================================
# artifacts/ —— 离线制品（k3s 二进制、镜像 tar 包）
# =============================================================================
# 这个目录放 `K3S_INSTALL_MODE=offline` 时需要的二进制与镜像。
#
# 目录结构:
#   k3s              k3s 二进制（架构对应控制机的架构，amd64/arm64）
#   k3s.version      k3s 版本号（例如 v1.31.4+k3s1）
#   helm             helm 二进制（用于安装本地 chart，可选）
#   images/*.tar     镜像 tar 包，离线时用 k3s ctr images import 导入
#
# 怎么准备:
#   在**能访问互联网**的机器上跑:
#     ./production/scripts/fetch-artifacts.sh
#   然后把整个 artifacts/ 目录（含 images/）拷贝到离线控制机的同路径。
#
# 默认模式（K3S_INSTALL_MODE=online）不需要这个目录，bootstrap.sh 会跳过。
#
# ⚠️ 本目录内容不入 git（二进制体积大）。只保留 README.md。
# =============================================================================
