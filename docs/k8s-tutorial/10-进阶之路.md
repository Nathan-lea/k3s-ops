## 2. 生产化路线图（按优先级）

> 状态说明：**已覆盖** = 教程已有章节；**部分覆盖** = 有基础但缺实战闭环；**待补** = 后续计划（见 `docs/tutorial-review-backlog.md`）。

### 第一阶段：加固（基础，必做）

1. **高可用 / 节点生命周期**（已覆盖教学实战）：本项目默认单 server（嵌入式 etcd）。生产至少 3 server；节点维护见 38，装前参数见 45，`k3s-ops.sh add-node/remove-node/upgrade/backup/restore` 生命周期运维见 46。仍待补：多 server HA 实操与生产变更流程。
2. **备份与恢复**（已覆盖教学实战）：08/12 覆盖 etcd snapshot 与 etcdctl，46 覆盖 `k3s-ops.sh backup/restore` 流程，48 覆盖 **k3s 标准快照命令为主线** + PV 数据备份恢复实操 + restore 检查清单/验收 + Velero/异地备份选型。仍待补：隔离沙箱中的真实 etcd restore 全量演练、生产级异地备份自动化。
3. **Secret 管理**（已覆盖入门/实战）：SOPS+age、External Secrets、RBAC 边界与 SOPS/SealedSecrets/ESO/Vault 选型见 50；生产仍需结合 etcd 加密、KMS、审计与动态凭据。
4. **镜像仓库与供应链**（待补）：私有 registry（Harbor）、镜像同步、签名/扫描、离线交付。

### 第二阶段：可观测（上线前提）

1. **指标**（已覆盖教学实战）：Prometheus/kube-prometheus-stack 部署与裁剪见 47；仓库已有 `addons/monitoring/values.yaml`。受当前双节点实验资源限制，完整生产规模部署仍需扩容后验证。
2. **告警**（已覆盖教学实战）：Alertmanager 基础配置与告警验证思路见 47；生产告警路由/值班联动待补。
3. **日志**（已覆盖教学实战）：Loki + Promtail + Grafana 轻量日志采集与 LogQL 排障见 49；受当前实验资源限制，生产级 HA/对象存储/告警联动待补。
4. **追踪**（待补）：OpenTelemetry/Jaeger/Tempo。

### 第三阶段：应用治理（部分已覆盖）

## 6. 学习建议（避免走弯路）

1. **概念先于工具**：先读懂对象模型（Pod 为何短暂、期望状态为何重要），再学 kubectl 技巧。
2. **动手高于背诵**：每个概念在本环境敲一遍，出问题就用 `describe` + `events` 排查 —— 排障能力比命令记忆值钱。
3. **按层建立心智模型**：容器层 → Pod 层 → 控制器层 → Service/网络层 → 存储层 → 安全层，一层层叠。
4. **读官方文档**：本教程是「带着走一遍」，细节以官方文档为准；遇到陌生字段直接查官方 reference。
5. **保持破坏欲**：在练习命名空间里大胆删、改、造故障，直到能凭直觉判断「这现象说明哪一层有问题」。

## 7. 结语

本教程基于真实 k3s 集群（k3s-demo：server-1 192.168.56.10 + agent-1 192.168.56.20），从零走到「能独立部署、调试、备份一个完整应用」。剩下的路：把第 2 节的生产化清单逐项落地，用 CKA 备考检验掌握度，把 GitOps 和多集群纳入日常工作流。

祝学习顺利。有问题时，先 `kubectl get events`。
