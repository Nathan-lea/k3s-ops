## 2. 生产化路线图（按优先级）

### 第一阶段：加固（基础，必做）

1. **高可用**：本项目拓扑是单 server（嵌入式 etcd 单节点）。生产至少 3 server（本项目的多节点模式：`nodes.yml` 增加 server-2/3，参考 `docs/architecture.md` 与 `k3s-ops.sh add-node`）。
2. **备份策略落地**：`--etcd-snapshot-schedule-cron` + 异地存储（把快照从 VM 拷到宿主机/对象存储）。第 08 章只演示了手动快照。
3. **Secret 加密**：etcd 静态加密（`kube-apiserver-arg: encryption-provider-config`）或用外部 Secret 管理（SealedSecrets / External Secrets Operator / Vault）。
4. **镜像仓库**：离线环境（本例从 docker.1panel.live 拉镜像）在生产应换成**私有 registry（Harbor）** + 镜像签名校验。

### 第二阶段：可观测（上线前提）

1. **指标**：Prometheus Operator / kube-prometheus-stack（本项目 addons 目录有监控 values，可参考 `addons/monitoring/`）。
2. **告警**：Alertmanager + 路由（Kubernetes 核心告警：NodeDown、PodCrashLoop、PVC 满）。
3. **日志**：Loki/EFK 收集集群与应用日志。
4. **追踪**：OpenTelemetry（分布式链路）。

### 第三阶段：应用治理

1. **服务网格**：Istio / Linkerd（重流量治理时引入）。
2. **GitOps**：ArgoCD / Fleet（本项目 Rancher 自带 Fleet，声明式交付）
3. **策略**：OPA Gatekeeper / Kyverno（准入控制策略）。
4. **多集群**：Rancher 多集群管理（本项目设计里 Rancher 就是多集群入口）。

## 3. 认证备考方向

| 认证 | 面向 | 与本教程关系 |

| **CKA**（Kubernetes Administrator） | 集群运维管理 | 对应 02/03/06/07/08 章，重点：排障、备份恢复、RBAC |

## 6. 学习建议（避免走弯路）

1. **概念先于工具**：先读懂对象模型（Pod 为何短暂、期望状态为何重要），再学 kubectl 技巧。
2. **动手高于背诵**：每个概念在本环境敲一遍，出问题就用 `describe` + `events` 排查 —— 排障能力比命令记忆值钱。
3. **按层建立心智模型**：容器层 → Pod 层 → 控制器层 → Service/网络层 → 存储层 → 安全层，一层层叠。
4. **读官方文档**：本教程是「带着走一遍」，细节以官方文档为准；遇到陌生字段直接查官方 reference。
5. **保持破坏欲**：在练习命名空间里大胆删、改、造故障，直到能凭直觉判断「这现象说明哪一层有问题」。

## 7. 结语

本教程基于真实 k3s 集群（k3s-demo：server-1 192.168.56.10 + agent-1 192.168.56.20），从零走到「能独立部署、调试、备份一个完整应用」。剩下的路：把第 2 节的生产化清单逐项落地，用 CKA 备考检验掌握度，把 GitOps 和多集群纳入日常工作流。

祝学习顺利。有问题时，先 `kubectl get events`。
